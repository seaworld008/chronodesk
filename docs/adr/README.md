# Architecture Decision Records

Architecture Decision Records (ADRs) capture durable choices that future
maintainers and coding agents should not repeatedly re-litigate.

## Status values

- `Proposed`: open for review.
- `Accepted`: current implementation direction.
- `Superseded`: replaced by a later ADR.
- `Deprecated`: retained only for historical context.
