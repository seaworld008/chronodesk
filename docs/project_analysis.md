# 项目分析（基线）

本分析文档用于快速建立全局理解。详细模块信息请查看 `docs/PROJECT_MANUAL.md`。

## 产品与业务
ChronoDesk 解决客服工单流程中的协作与治理问题，核心价值是将“受理、分配、处理、升级、回溯、统计”串成统一闭环。

## 架构结论
- 后端采用分层结构（handler/service/model/middleware），具备良好的职责分离。
- 前端基于 React-Admin 资源模型，业务模块边界清晰，扩展成本可控。
- PostgreSQL + Redis 的组合满足事务一致性与读写性能需求。

## 工程结论
- 具备可运行的本地开发链路与容器链路。
- 测试体系覆盖 Go 单测、Pytest 冒烟与脚本集成检查。
- 文档已收敛到 `docs/`，应继续执行“单一真相源”原则。
